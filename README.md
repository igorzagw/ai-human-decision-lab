# AI-Human Decision Lab

**Модель рішення для відбудови громад.** Штучний інтелект аналізує дані,
знаходить закономірності та пропонує кілька варіантів дій із поясненням логіки
розрахунків. Людина перевіряє рекомендації, зважує реальні обставини, етичні
норми та інтереси громади — і ухвалює остаточне рішення.

Ключова ідея: **машина рахує, людина вирішує.** Застосунок побудовано так, щоб
цей розподіл не можна було обійти.

---

## Чотири етапи

| Етап | Хто діє | Що відбувається |
|------|---------|-----------------|
| 1. Дані | людина | Обирає задачу, описує умови громади, перелічує об'єкти |
| 2. Аналіз | алгоритм | Рахує бали, знаходить закономірності, пропонує три варіанти дій |
| 3. Перевірка | людина | Оцінює етичність і реалістичність, коригує пріоритети, читає заперечення |
| 4. Рішення | людина | Приймає, змінює або відмовляється — обов'язково з обґрунтуванням |

Перейти до четвертого етапу, не написавши обґрунтування, неможливо. Рішення без
причини не можна ані оскаржити, ані перевірити через рік.

---

## Три задачі — три різні методи

Це не один алгоритм із трьома наборами даних. Задачі різні за суттю, тому й
математика в них різна.

### 1. Пріоритизація об'єктів відбудови
**Задача про рюкзак, динамічне програмування.**
Об'єктів більше, ніж грошей. Модель максимізує сумарну користь за умови, що
сума вартостей не перевищує бюджет. Жадібний відбір «найкорисніше першим» дає
похибку: інколи два середні об'єкти разом кращі за один сильний.

### 2. Розподіл бюджету між сферами
**Гранична корисність зі спадною віддачею.**
Бюджет ділиться на 200 порцій, кожна йде туди, де просто зараз дає найбільший
приріст. Віддача спадає в міру насичення сфери, тому гроші розтікаються, а не
осідають в одній галузі.

### 3. Повернення переселенців
**Закон мінімуму (модель Лібіха).**
Тут навмисно не рахується середнє. Громада не буває «в середньому готова»: вона
приймає рівно стільки людей, скільки витримує найвужча життєво необхідна
підсистема. Розшити не найвужче місце, а найдешевше — типова помилка, і модель
показує, чому вона нічого не дає.

---

## Роль мовної моделі

Groq **пояснює і заперечує**, але **не рахує**. Усі числа приходять із
детермінованого алгоритму, який працює у браузері. Причина проста: мовна модель
переконливо помиляється в арифметиці, і перевірити її на захисті неможливо.
Розрахунок має бути відтворюваним, а формулювання — живим, тож робота поділена
за сильними сторонами.

На третьому етапі модель отримує окреме завдання: **не погоджуватись**. Вона
шукає слабкі місця обраного варіанта, називає групи людей, які від нього
програють, і умови, за яких рішення варто переглянути.

**Без ключа Groq застосунок не ламається.** Він складає ті самі пояснення
локально з тих самих чисел — гірше стилістично, але завжди. На захисті, де може
не бути інтернету, це важливіше за красу тексту.

---

## Приватність

- **Розрахунки виконуються у вашому браузері.** Дані громади не залишають
  пристрій.
- У Groq іде лише **текстова зведення результатів**. Перед відправкою її можна
  побачити повністю — кнопка «Що надсилалось».
- Ключ Groq зберігається лише у `localStorage` вашого браузера і **ніколи не
  потрапляє в репозиторій**.
- Мовну модель можна вимкнути — тоді застосунок працює повністю офлайн.

## Доступ

GitHub Pages на безкоштовному тарифі не вміє закривати сторінку паролем: сайт
завжди публічний. Тому доступ обмежує сам застосунок.

У репозиторії лежить **лише зашифрований блок** (`app.enc`): AES-256-GCM, ключ
виводиться з пароля через PBKDF2-SHA256, 310 000 ітерацій. Без пароля вміст
неможливо прочитати навіть із вихідного коду сторінки. Вихідники в репозиторій
не потрапляють — їхня зашифрована копія лежить у `src.enc`.

---

## Збірка

```bash
node build.mjs      # запитає пароль, збере app.enc і src.enc
node restore.mjs    # відновить src/ із src.enc, якщо робочу папку втрачено
```

Пароль запитується інтерактивно і ніде не зберігається. Після зміни будь-чого
у `src/` застосунок треба **зібрати заново** — інакше на сайті лишиться стара
версія.

Локальний запуск: будь-який статичний сервер (не `file://` — потрібен `fetch`
для `app.enc`).

```bash
python -m http.server 8080
```

## Структура

```
index.html      екран входу, розшифрування, монтування застосунку
app.enc         зашифрований застосунок  (збирається)
src.enc         зашифрована копія вихідників (збирається)
build.mjs       збірник і шифрувальник
restore.mjs     відновлення вихідників
src/            вихідний код (не комітиться)
  scenarios.js  предметна модель: що питаємо і за якими критеріями
  engine.js     обчислювальне ядро
  llm.js        шар Groq + локальні пояснення
  ui.js         чотири етапи
  app.html      каркас розмітки
  app.css       оформлення
```
